# 카뉴 (Kanew)

기사·블로그·Threads 링크를 붙여넣으면 인스타그램 카드뉴스(1080×1440 / 1080×1350)가 만들어지는 Windows 앱이에요.
원고 쓰기 → 사진·영상 찾기 → 템플릿 배치 → PNG·MP4 저장까지 한 번에 해요.

**[Windows용 무료 다운로드 (Kanew.exe)](https://github.com/echidna08/kanew/releases/latest/download/Kanew.exe)** · [소개 페이지](https://echidna08.github.io/kanew/)

## 필요한 것

- Windows 10/11 (설치 없이 바로 실행되는 포터블 exe)
- **Claude Pro 이상 구독 + Claude Code** — 원고는 내 PC에서 내 Claude 계정으로 만들어요. 카뉴에 따로 내는 AI 사용료는 없어요.
  설치 안내: https://docs.claude.com/en/docs/claude-code/setup

## 시작하기

1. `Kanew.exe` 다운로드 후 실행
2. Claude Code 설치 후 본인 Claude 계정으로 로그인
3. 카뉴에서 링크 붙여넣고 '원고 만들기'

처음 실행할 때 Windows가 '알 수 없는 게시자' 경고를 띄울 수 있어요. '추가 정보' → '실행'을 누르면 돼요. (베타라 아직 코드 서명 전이에요)

## 알아둘 것

- 템플릿 미리보기 사진은 모두 AI(FLUX 3 Image Klein)로 만든 이미지예요.
- 만든 카드의 저작권은 만든 사람에게 있어요. 원본 기사 글·사진은 각 저작권자의 것이니 게시 전에 출처를 확인해 주세요.
- Claude는 Anthropic의 상표이며, 카뉴는 Anthropic과 관련이 없습니다.
